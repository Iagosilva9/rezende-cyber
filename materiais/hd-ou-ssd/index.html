HD ou SSD? O guia para escolher e fazer a troca certa

A diferença real entre HD, SSD SATA e SSD NVMe, como saber qual o seu computador aceita e o passo a passo para trocar sem perder nada.

capítulo 01

A diferença em uma frase

O HD guarda os dados em discos que giram, com uma agulha que se move para ler. O SSD não tem partes móveis: guarda tudo em chips de memória, como um pen drive muito mais rápido. Resultado: o SSD liga o computador e abre programas em uma fração do tempo.

As velocidades variam conforme o modelo. Na prática, qualquer SSD já é uma mudança enorme para quem sai de um HD.

capítulo 02

Qual o seu computador aceita

  • SSD SATA 2,5": tem o mesmo formato do HD de notebook. Serve em quase todo computador que hoje usa HD.
  • SSD M.2 SATA: formato de "plaquinha", encaixa em slot M.2, mas com a velocidade do SATA.
  • SSD M.2 NVMe: mesmo formato de plaquinha, muito mais rápido. Precisa de um slot M.2 com suporte a NVMe (PCIe).
Confira antes de comprar

Um slot M.2 pode aceitar só SATA, só NVMe ou os dois. Veja o manual ou o site do fabricante pelo modelo exato do notebook ou da placa-mãe. Comprar o tipo errado é o erro mais comum.

capítulo 03

Quando o HD ainda faz sentido

  • Backup e arquivos grandes que você acessa pouco (fotos antigas, vídeos).
  • Segundo disco em desktops: SSD para o sistema e programas, HD para guardar arquivos.
  • Quando o orçamento é curto e a necessidade é muito espaço.

Para o disco onde fica o Windows, hoje a recomendação é sempre SSD.

capítulo 04

Trocando sem perder nada

  1. Faça backup dos arquivos importantes antes de qualquer coisa.
  2. Escolha um SSD com capacidade igual ou maior que o espaço usado hoje no HD. Para Windows e uso comum, 500 GB é um bom ponto de partida.
  3. Clone o disco: com um adaptador USB, copie o HD inteiro para o SSD usando um programa de clonagem. Assim o Windows, os programas e os arquivos vão juntos.
  4. Troque o disco, ligue o computador e confira se tudo abriu normalmente.
  5. Guarde o HD antigo por algumas semanas antes de reaproveitar ou descartar.

Outra opção é instalar o Windows do zero no SSD e copiar os arquivos depois. Dá mais trabalho, mas o sistema começa limpo.

capítulo 05

Cuidados com SSD

  • Vida útil: SSDs têm limite de gravação (TBW), mas para uso doméstico e de escritório ele costuma durar muitos anos.
  • Recuperação de dados é mais difícil: arquivos apagados em SSD tendem a ser limpos rapidamente. Backup é obrigatório.
  • Não precisa desfragmentar: o Windows faz a otimização correta sozinho.
  • Deixe uma parte livre, em torno de 10 a 20%, para manter o desempenho.

capítulo 06

Descarte com segurança

Antes de vender, doar ou descartar um HD ou SSD antigo, apague os dados de forma segura. Formatar ou apagar arquivos não basta: com as ferramentas certas é possível recuperar muita coisa de um disco só formatado.

  • Use a função de apagamento seguro do fabricante do SSD ou um programa de sobrescrita para HD.
  • Para discos com dados sensíveis de empresa, a destruição física é a opção mais segura.
